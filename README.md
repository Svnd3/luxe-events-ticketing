# 🎟️ LuxeTix — Premium Event Ticketing Platform

LuxeTix is a modern, luxury-inspired event ticketing platform designed to deliver a smooth, premium experience for discovering, booking, and managing event tickets.

Built with performance, fairness, and real-world usability in mind — including M-Pesa payments and WhatsApp support.

---

## ✨ Features

### 🎨 Premium User Experience
- Luxury dark UI with glassmorphism
- Smooth animations powered by Framer Motion
- Fully responsive (mobile + desktop)
- Clean typography and modern layout

### 🎫 Event & Ticket System
- Browse events by category, location, and price
- Detailed event pages with ticket tiers:
  - VIP
  - Regular
  - Early Bird
- Unique ticket generation
- QR codes for ticket validation

### 💳 Payments (M-Pesa Integration)
- STK Push simulation / integration
- Secure transaction handling
- Real-time payment feedback
- Transaction history tracking

### 💬 WhatsApp Support
- Direct communication via WhatsApp
- Pre-filled messages for support
- “Contact Organizer” feature

### 🌍 Smart Pricing System
- Region-based pricing (country-aware)
- Transparent breakdown:
  - Base price
  - Platform fee
  - Organizer earnings
- Fair pricing model:
  - Prevents user exploitation
  - Ensures platform sustainability

### 👤 User Dashboard
- View purchased tickets
- QR code access
- Profile management
- Transaction history

### 🛠️ Admin Panel
- Create, edit, delete events
- Manage ticket tiers and pricing
- View sales analytics
